# 蓝培医疗网站新闻自动采集与发布指南

## 栏目分类
- **行业资讯** (industry): 医疗行业政策、医院动态、跨境医疗、国际医疗合作、医疗技术进展等
- **公司资讯** (company): 蓝培医疗公司动态、新合作、服务升级、团队消息等
- **药闻速递** (drug): 药品获批、新药上市、仿制药动态、药品用法用量科普等

## 自动采集流程

### 1. 新闻搜索关键词（按优先级排列）

#### 药闻速递（主力，每天至少1篇）
- **GLP-1/减重药**（最高优先）: "GLP-1 减重药" "司美格鲁肽" "替尔泊肽" "埃诺格鲁肽" "玛仕度肽" "口服GLP-1"
- **抗肿瘤新药**（核心业务）: "靶向药 新适应症" "ADC药物 获批" "NMPA 肿瘤药" "ASCO 2026" "肺癌靶向药"
- **仿制药/原研药**（差异化优势）: "仿制药获批 NMPA" "原研药 仿制药 价格" "印度仿制药" "老挝仿制药"
- **罕见病/新靶点**: "罕见病药 获批" "BCL-2抑制剂" "KRAS G12C"

#### 行业资讯（每天0-1篇）
- **医保政策**: "医保目录 调整" "医保报销 新规" "国谈药 进院"
- **跨境医疗**（蓝培核心）: "跨境医疗 中国" "医疗旅游 2026" "国际医疗合作" "境外就医"
- **行业动态**: "NMPA政策" "药品管理法" "医疗合规"

#### 公司资讯
- 需人工提供或从蓝培官方渠道获取

|----------|------|-------------|------|
| GLP-1/减重药 | ⭐⭐⭐⭐⭐ | 2-3篇 | 当前搜索量最大，持续热点 |

| 其他行业动态 | ⭐⭐ | 0-1篇 | 视新闻价值而定 |

### 1.2 选题筛选原则
1. **与蓝培业务强相关**：抗肿瘤药、仿制药、跨境医疗优先
2. **搜索热度优先**：GLP-1、ASCO等热搜话题优先覆盖
3. **患者视角**：关注对"药价、可及性、替代方案"有实际影响的新闻
4. **避免同质化**：同一事件不重复写，换角度切入（如GLP-1可写"获批""价格""副作用"不同角度）
5. **时效性**：优先最近1-3天新闻，超过7天的一般不写

### 2. 文章生成规则
- 标题: 简洁有力，包含核心关键词，吸引患者点击
- 正文: 300-800字，结构化（背景→核心内容→对患者的影响→蓝培相关服务引导）
- **蓝培服务引导**：根据文章主题精准引导
  - GLP-1/减重药 → 引导咨询全球减重药方案（含印度仿制司美格鲁肽等）
  - 抗肿瘤新药 → 引导咨询全球抗癌药获取渠道（老挝/印度/孟加拉仿制药）
  - 仿制药/原研药价格 → 引导咨询性价比更高的仿制药方案
  - 医保政策 → 引导咨询医保覆盖外的替代方案
  - 跨境医疗 → 引导咨询蓝培跨境医疗服务
- 必须在文末添加免责声明
- 所有咨询引导走WhatsApp/微信，严禁京东链接
- 文章末尾添加"相关阅读"：链接到蓝培公众号同类药品文章（如有）

### 3. 文件命名
- 格式: `{序号}-{关键词拼音}.html`
- 序号从011开始（001-010已被药品科普占用）
- 示例: `011-taladantomab.html`, `012-mayo-alliance.html`

### 4. 文章HTML生成
使用模板: `./蓝培医疗文章/news/news-article-template.html`
替换变量: {{TITLE}}, {{DESCRIPTION}}, {{KEYWORDS}}, {{CATEGORY_CLASS}}, {{CATEGORY_NAME}}, {{DATE}}, {{CONTENT}}

### 5. 更新新闻索引
在 `./蓝培医疗文章/news/index.html` 的 `<!-- ARTICLES_INSERT_POINT -->` 后插入新文章卡片:
```html
<div class="article-card" data-category="{industry|company|drug}">
    <h3><a href="/news/{filename}">{标题}</a></h3>
    <div class="article-meta"><span class="tag tag-{category}">{分类名}</span><span class="article-date"><i class="far fa-calendar-alt mr-1"></i>{YYYY-MM-DD}</span></div>
</div>
```
新文章插入到 ARTICLES_INSERT_POINT 之后（最新的在前）。

**⚠️ 日期必填规范（2026-06-19 兰姐明确要求）**：
- {YYYY-MM-DD} 必须是**当天日期**（不要写发布日期以外的旧日期）
- 缺失日期 = 卡片显示不完整，部署前必须检查
- 工作流产物（药闻/行业/公司三类）的 article-card 必须包含完整的 article-meta（分类标签 + 日期）
- 早期 001-128 用法用量科普文可保持原状（无日期无标签），不强制改造

### 6. 部署到GitHub
```bash
cd /path/to/lanpei-medical-site
# 复制新文章和更新的index.html到部署目录
cp ./蓝培医疗文章/news/{filename} ./news/
cp ./蓝培医疗文章/news/index.html ./news/index.html
git add .
git commit -m "feat: add news article - {标题}"
git push
```

### 7. 质量检查
- 确认文章链接可访问
- 确认分类标签正确
- 确认咨询渠道（WhatsApp/微信）链接正确
- 确认无京东链接
- 确认百度统计代码存在
